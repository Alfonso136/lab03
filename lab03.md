# Laboratorio 03 - Comandos y utilidades básicas en xv6

## ls
Lista el contenido del sistema de archivos.
![ls](imgs/01_ls.png)

## echo
Imprime texto; con > lo guarda en un archivo.
![echo](imgs/02_echo.png)

## cat
Muestra el contenido de un archivo.
![cat](imgs/03_cat.png)

## wc
Cuenta líneas, palabras y caracteres.
![wc](imgs/04_wc.png)

## grep
Busca un texto dentro de un archivo.
![grep](imgs/05_grep.png)

## mkdir
Crea una carpeta.
![mkdir](imgs/06_mkdir.png)

## rm
Elimina un archivo o carpeta vacía.
![rm](imgs/07_rm.png)

## ln
Crea un enlace: dos nombres para el mismo contenido.
![ln](imgs/08_ln.png)
